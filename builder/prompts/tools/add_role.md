## description

Add a character role. Bind it to an NPC type from the catalog, never to an id or a location; the simulation decides who, where and when. Write the persona as story: personality, needs, drives.

## persona

Personality, needs and story on top of the mathematical background.

## npcType

Type string from the NPC type catalog.

## reservedName

Only for a pre-instanced story NPC with a fixed identity.
